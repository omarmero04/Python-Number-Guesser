# Python-Number-Guesser
A simple, classic number-guessing game implemented in Python. The game selects a random integer between 1 and 10, and the player must try to guess it within a user-defined number of attempts. It provides hints ("try higher" or "try smaller") after each incorrect guess and displays the correct number if the player runs out of tries.

This is an interactive command-line interface (CLI) game where the user attempts to guess a randomly selected number within a limited number of attempts. It's a simple, classic exercise in Python that demonstrates basic input/output, loops, and conditional logic.

✨ Features
Random Number Generation: The secret number is randomly selected by the computer (between 1 and 10).

Custom Tries: The player defines the total number of attempts they get before the game starts.

Hints: Provide feedback ("try a higher number" or "try a smaller number") after each incorrect guess to guide the player.

Win/Loss Condition: Clearly informs the player if they successfully guessed the number and how many tries it took, or if they ran out of attempts and lost.

Begin entering your guess until you find the correct number or run out of attempts!
